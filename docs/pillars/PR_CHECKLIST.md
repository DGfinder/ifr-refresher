# IFR Refresher PR / Change Checklist

## Scope

- [ ] Executor declared: Hermes/Codex, Human, or other.
- [ ] Tier considered: Tier 2 now; Tier 3 if public/paying/external pilot.
- [ ] Problem and acceptance criteria stated.
- [ ] Non-goals stated for broad work.
- [ ] Diff is scoped and reviewable.

## Code quality

- [ ] Domain names match IFR/study workflow language.
- [ ] No dead code, debug logs, or stale comments.
- [ ] No duplicated quiz/drill/progress business rules.
- [ ] Errors are explicit without leaking local/private data.

## Data/content

- [ ] Aviation content changes include source and review date.
- [ ] JSON/content shape tests pass.
- [ ] Content disclaimer remains accurate.

## Frontend/PWA

- [ ] Tokens used for colours/theming.
- [ ] Loading/empty/error/offline/degraded states considered.
- [ ] Keyboard and accessibility basics verified for changed flows.
- [ ] Responsive mobile/desktop checks run for UI changes.
- [ ] Service-worker/offline smoke run for PWA changes.
