# Retired UI expectations

Preserved tests for the superseded quiz, flashcard, radio, progress and layered-study experience. Those public routes now return to the source-only contents. These expectations are no longer the product contract.

The active suite in tests/e2e covers baseline navigation, source pages, search, redirects, accessibility, responsive layout and brand previews. No active assertions were disabled to pass a run; the replacement browser suite has not yet been executed. The default Playwright configuration remains scoped to tests/e2e.
